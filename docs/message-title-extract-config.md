# 单条消息的目录与文件名

在「路径设置 → 快捷设置」点击「消息每条单独一篇」并确认，可以为消息使用独立目录和去掉日期、类型前后缀的标题。自定义时展开「消息处理 → 消息单独设置」。已有笔记不会因为应用预设而移动。

「消息单独设置」默认关闭，仅在不合并或双写时生效。文件夹、文件名、两项日期格式、笔记属性及正文模板分别留空时，使用文章的对应设置；双写的合并副本继续使用原来的合并模板。同名消息沿用现有编号规则，不会互相覆盖。

| 变量 | 含义 |
|---|---|
| `{{{title}}}` | 开启独立设置后的单条消息使用干净标题 |
| `{{{rawTitle}}}` | 原始完整标题 |
| `{{{messageTitle}}}` | 去掉固定前后缀的消息标题；普通文章保持原标题 |
| `{{{messageType}}}` | 文本、图片、视频、语音、文件、聊天记录、笔记或媒体 |

例如原始标题 `同步助手_20260824_空调蓝图打印_文本`，独立消息的 `{{{title}}}` 为 `空调蓝图打印`，`{{{rawTitle}}}` 保留完整标题，`{{{messageType}}}` 为 `文本`。

需要自定义剥壳规则时，可在文件名模板中使用：

```text
{{#extract}}{{{rawTitle}}}|^同步助手_\d{8}_([\s\S]+)_[^_]+$|$1{{/extract}}
```

规则没有命中或结果为空时原样返回取值。日期等其它变量与用法见 [模板变量](../TEMPLATE-VARIABLES.md)。市场版保留 Templater 标签文本，不执行跨插件插值。
